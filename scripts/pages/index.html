添加软件源

先选择实际板卡，再使用下方命令。testing 是待真机验证的候选版本。安装前请核对公钥指纹：476B F598 CA47 F121 46EF 1862 0F6E DF1B 5C41 F3EC。

curl -fsS https://apt.100ask.net/dshanpi-archive-keyring.gpg \
  -o /tmp/dshanpi-archive-keyring.gpg
gpg --show-keys --with-fingerprint /tmp/dshanpi-archive-keyring.gpg
sudo install -m 0644 /tmp/dshanpi-archive-keyring.gpg /usr/share/keyrings/
sudo tee /etc/apt/sources.list.d/dshanpi.sources <<'EOF'
Types: deb
URIs: https://apt.100ask.net
Suites: noble-testing
Components: common dshanpi-a1-cm5
Architectures: arm64 all
Signed-By: /usr/share/keyrings/dshanpi-archive-keyring.gpg
EOF
sudo apt update
sudo apt install dspi-config

管理系统版本

初次使用平台版本管理前，安装适合当前板卡和 CLI／桌面环境的 release 元包。它会安装精确版本的内核、DTB、BSP 和驱动，请先在测试板上验证。

apt-cache policy dshanpi-a1-cm5-release-core
# 桌面镜像使用 dshanpi-a1-cm5-release-desktop
sudo apt install -t noble-testing dshanpi-a1-cm5-release-core
dspi-config update list
sudo dspi-config update install <版本>
sudo dspi-config update rollback

回滚要求仓库中存在更早版本。测试通道不会随普通系统升级自动选入；U-Boot 不在在线升级集合中。
